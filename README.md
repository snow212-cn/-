# 暴走英雄坛 · 真元方案优化助手

这是一个为《暴走英雄坛》玩家设计的真元获取方案优化工具。它可以根据你的武学配置、修炼速度和减免情况，自动计算出最优的真元提升路径。

## 运行与部署

View your app in AI Studio: https://ai.studio/apps/drive/1w8VqA8gIuNyy6uEfM59d-lhsuG99RZ3e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
